# Python Games

Repositório para jogos feitos em Python.

## Jogos

| Jogo | Descrição |
|------|-----------|
| [Wordle](./wordle) | Versão para terminal, com palavras em português e temas |

Cada jogo tem seu próprio README, com as instruções de como jogar.

## Como usar

```bash
git clone https://github.com/laissemy/python_games.git
cd python_games
```

Depois, entre na pasta do jogo que quiser e leia o README dele.
